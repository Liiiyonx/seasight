放置点（料槽）

      

        抓取闭环的最后一步：把袋子放进臂座旁边的料槽。抓取点每帧由视觉现算，
        放置点是固定工位，示教一次即可。示教方法：用上面的「手动点动」把臂摆到槽口正上方
        → 点「用当前姿态作放置点」。也可以直接填工作平面坐标（m，标定坐标系）。
        没设放置点时抓取会直接拒绝开工 —— 夹起来没地方放比不抓更糟。

安全 先看这段

      

        「软停止」不是物理急停：厂商的 ROS 消息集里只有 MultiRawIdPosDur，
        没有卸力/急停消息。软停止做的是「中止作业 + 把 6 个舵机锁在当前回读位置」，
        机械臂会停在原地但仍然带电、仍有保持力矩。真急停只能断电或拍下电源。

键盘控制 先点一下这里让页面获得焦点

      

        方向键在水平面上移动爪子，W/S 升降，J/L 调 Pitch（俯仰角）。
        每次按下的步长由下面的「步长」决定。输入框获得焦点时按键不会驱动机械臂（防止打字时误动）。
      

      

        
W上升 z+

        
←↑→ ↓水平面 x/y

        
S下降 z−

        
JLPitch −/+（更朝下 / 更平）

      

      

        
        
        
      

      
时长越小动得越快。500ms 适合微调，150ms 适合连按；太短舵机会丢步。

    


    

      
位置控制 给坐标，IK 现算

      

        填工作平面坐标与俯仰角，由厂商 ArmIK 现算四个关节脉宽 —— 不用自己调 id3~id6。
        坐标系与标定一致：原点 = 臂座安装面在地面的投影，单位 m；
        Pitch 区间 [-180, 0]，-180 = 竖直朝下，-65 = 待命位。

6 · 抓取作业

      
全自动闭环：检测 → 锁定（滤浮标）→ 视觉伺服逼近 → 精准夹取 → 双证据验证 → 放入旁边的料槽。平台派单后也可由桥接层自动触发同一套闭环（一次派单抓一袋，抓完即止）。
