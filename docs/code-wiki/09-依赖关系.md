## 2. 关键跨模块依赖（易踩坑处）

| 依赖方向 | 载体 | 说明 |
| --- | --- | --- |
| **backend → edge/detector** | `from edge.detector.detector import CvDetector`（3 处：api/v1/ai.py、api/v1/assistant.py、services/assistant/tools.py） | 后端镜像构建上下文只有 `./backend`，靠 docker-compose 把 `./edge` 只读挂到 `/edge`，代码用 `Path(__file__).parents[4]` 反推仓库根定位。**cv2+numpy 是后端必需依赖不是可选**（曾漏列导致图片分析线上 500） |
| **backend → ai-service** | httpx 调 `AI_SERVICE_URL:8081` | 独立容器独立镜像（Dockerfile.ai），依赖只有 onnxruntime+pillow+opencv，便于独立部署到边缘设备 |
| **ai-service → ml/** | 挂载 `./ml:/ml`，`AI_MODEL_PATH=/ml/models/best.onnx` | 模型产物由 ml 管线产出 |
| **frontend → backend** | `/api` 代理 → :8000；WS `/api/v1/ws/alerts` | 契约由 `check_api_contract.py` 对账 |
| **frontend → go2rtc** | `/stream` 代理 → :1984 | 生产经 Nginx 反代，同源相对路径 |
| **edge → EMQX** | MQTT QoS1 上报 | 主题树契约 `Topics` 类（backend 与 edge 双方引用同一规范） |
| **nexent → backend** | httpx `/api/v1` | 不直接 import 后端模型；认证走专用账号 + token 自动刷新 |
| **backend → artifacts/** | 只读挂载 `agent_evals` | 缺挂载则评测接口永远 6008、前端质量雷达空态 |

## 3. 外部基础设施依赖

| 组件 | 版本 | 用途 | 替代/降级 |
| --- | --- | --- | --- |
| PostgreSQL + PostGIS | 14-3.3 | 主库 + 空间索引 | 裸机模式缺失时 `/health` 如实报 down |
| Redis | 7-alpine | 缓存 + Streams 队列（stream:events / dispatch / dead_letter） | — |
| EMQX | 5.8 | MQTT 设备接入（认证 bootstrap.csv + ACL） | 模拟器同为 MQTT 客户端，可无缝替换真实设备 |
| MinIO | latest | 告警帧/作业影像（bucket: events，匿名只读下载） | — |
| go2rtc | latest | RTSP → WebRTC/FLV 流媒体 | 不经后端，前端直连 |
| 天地图 API | — | 前端地图瓦片（政务合规） | — |
| 企业微信 webhook | 可选 | 告警外发；**失败不阻塞派单主流程** | 留空=禁用 |
| OpenAI-compatible LLM | 可选 | Agent 规划（`agent_model_*`）与助手（`assistant_model_*`），相互独立 | 缺省自动退规则模式，核心能力不下降 |

## 7. 依赖健康度检查

- 前后端接口漂移：`make check-api`
- 契约漂移（MQTT/枚举/映射）：`make check-contract`（+ selftest 自证）
- 依赖漏列这类问题（cv2、Pillow 两起事故）：已在 requirements 注释中留档，测试覆盖 `test_container_script_invocation.py` 等
