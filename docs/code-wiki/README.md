## 一句话理解这个项目

**岸基摄像头发现垃圾 → 平台自动派单 → 水面机器人清理 → 数据回传形成治理闭环。**

平台是中枢而非显示屏：识别到垃圾不是"弹个框"，而是产生**事件**、触发**派单**、形成可追溯**工单**。去掉机器人本体后，软件侧仍可作为「海漂垃圾治理决策与调度智能体」独立运行（机器人只是可替换的 MQTT 作业端）。
